# Experiment 8: MITRE ATT&CK Mapping

## Aim and scope

Review the MITRE ATT&CK Enterprise framework and ATT&CK Navigator as tools for describing observed security behavior. This copy contains framework-review screenshots only; exploit commands and shell-access evidence are not included.

## Theory

MITRE ATT&CK is a knowledge base for describing adversary behavior. A **tactic** represents an objective, while a **technique** describes a method that may be used to achieve it. ATT&CK Navigator provides a visual interface for exploring the Enterprise matrix.

The following technique descriptions were reviewed:

- [T1190: Exploit Public-Facing Application](https://attack.mitre.org/techniques/T1190/)
- [T1068: Exploitation for Privilege Escalation](https://attack.mitre.org/techniques/T1068/)

## Procedure

1. Review the Enterprise matrix in ATT&CK.
2. Open ATT&CK Navigator and inspect the Enterprise matrix.
3. Select T1190 for review, then compare its criteria with available evidence.
4. Review T1068 and distinguish a possible classification from a confirmed finding.

## Result

The Enterprise matrix and two technique descriptions were reviewed. Selecting a technique is not evidence that an activity matches it; any mapping should be limited to what authorized evidence supports.
